# Maven Market Sales Analysis

## Project Overview
An Excel-based sales analysis project focused on evaluating sales, profit, returns, and branch and product performance.

## Tools & Technologies
Excel | Power Query | Power Pivot | Pivot Tables | Pivot Charts

## Project Objectives
- Analyze sales and profit performance.
- Evaluate branch and product performance.
- Analyze return trends.
- Monitor key business KPIs.

## Key Work
- Cleaned and transformed sales data using Power Query.
- Built a data model using Power Pivot.
- Analyzed sales, profit, returns, and branch/product performance using Pivot Tables and Charts.
- Developed an interactive Excel dashboard with KPIs and actionable business insights.
